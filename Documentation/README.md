# Documentation

This folder contains the documentation for the device, written in Markdown so it
reads in a browser, in a terminal, or through a screen reader without any
conversion step.

- `ORDERING.md`: ordering the assembled circuit board from JLCPCB.
- `ASSEMBLY.md`: printing the parts, choosing a keyboard switch and a keycap,
  building the device, and testing it.
- `BOM.csv`: the full bill of materials, including what you print and what you buy.

Every photograph referenced by these documents is described in the surrounding
text, so no instruction depends on being able to see an image.
